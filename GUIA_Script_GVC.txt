============================================================
GUIA DE USO - Script_GVC.ps1
Correção SonicWall GVC + Wi-Fi lento
============================================================

O QUE FAZ O SCRIPT?
-------------------
Este script corrige problemas de conexão Wi-Fi lenta, especialmente 
relacionados ao SonicWall GVC. Ele:

• Desativa o RSC (Receive Side Coalescing) do adaptador Wi-Fi
• Desativa offloading de pacotes e checksums TCP/UDP
• Ajusta propriedades avançadas para melhor estabilidade
• Reinicia o adaptador de rede para aplicar as mudanças
• Exibe relatórios antes e depois das modificações


PRÉ-REQUISITOS
---------------
✓ Windows 10/11 ou superior
✓ PowerShell 3.0 ou superior
✓ Direitos de ADMINISTRADOR (obrigatório!)
✓ Conexão Wi-Fi ativa


COMO EXECUTAR
--------------

1. ABRIR PowerShell COMO ADMINISTRADOR:
   - Clique em Start (botão Windows)
   - Digite "PowerShell"
   - Clique com botão direito em "Windows PowerShell"
   - Selecione "Executar como administrador"

2. NAVEGAR PARA A PASTA DO SCRIPT:
   cd "C:\Script" (Exemplo)

3. EXECUTAR O SCRIPT:

   Opção A - Com adaptador padrão (Wi-Fi):
   .\Script_GVC.ps1

   Opção B - Com adaptador customizado:
   .\Script_GVC.ps1 -AdapterName "Ethernet"

   Opção C - Se receber erro de execução de scripts:
   Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
   .\Script_GVC.ps1


POSSÍVEIS AVISOS DURANTE A EXECUÇÃO
-------------------------------------
• "ERRO: Adaptador 'Wi-Fi' não encontrado"
  → O adaptador pode ter outro nome. Execute sem parâmetros
     para ver a lista de adaptadores disponíveis.

• "Falha ao desativar RSC"
  → Normal em alguns adaptadores. O script aplicará ajustes
     alternativos automaticamente.

• "Não encontrado ou não aplicável"
  → Significa que a propriedade não existe neste adaptador.
     É seguro ignorar.


ESPERADO APÓS EXECUÇÃO
-----------------------
✓ RSC desativado em IPv4 e IPv6
✓ Offloading reduzido
✓ Adaptador reiniciado
✓ Conexão Wi-Fi mais estável


DESFAZER ALTERAÇÕES
--------------------
Se algo não funcionar como esperado:

1. Acesse: Configurações → Rede e Internet → Wi-Fi
2. Clique em "Gerenciar adaptadores conhecidos"
3. Clique direito no Wi-Fi → Propriedades
4. Clique em "Configurar"
5. Abra a aba "Avançado"
6. Restaure os valores padrão das propriedades
